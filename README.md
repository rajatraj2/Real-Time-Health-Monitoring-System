Real-Time Health Monitoring System
This project was developed during my Research Internship at NIT Rourkela. It is a mobile application designed to track and visualize critical health parameters in real-time, providing an efficient way for users and healthcare providers to monitor patient health.

🚀 Key Features
Live Health Tracking: Real-time display of vital signs including Heart Rate, SpO₂ (Oxygen Levels), and Glucose levels.

Real-time Database: Integrated Firebase for seamless data synchronization and cloud storage.

Smart Alerts: Implemented notification mechanisms to alert users when health parameters cross normal thresholds.

Data Visualization: Interactive dashboards designed for clear and effective monitoring of health history.
